# Configurando Git

> [!IMPORTANT] 
> Abrir a pasta do meu projeto e clicar com o botão direito do mouse em qualquer espaço vazio e vai em terminal e abra com ele
## Formato Codigo

### NO CURSO

> LIMPAR GIT NA AREA DE TRABALHO (DESKTOP)

```sh
git config --local user.name "arthur567123"
git config --local user.email "arthur57apple@gmail.com"
git pull
git add .
git commit -m "Mensagem sobre a alteração que eu fiz"
git push
```

Se você apenas copiar, ir to terminal e colar funciona do mesmo jeito de anotar manualmente no terminal. 
### EM CASA

> FAZER GIT CONFIG LOCAL EM CASA SOMENTE SE TIVER UMA SÓ CONTA DO GIT 
#### Fazer uma vez somente o global, depois não precisa mais
```sh
git config --global user.name "arthur567123"
git config --global user.email "arthur57apple@gmail.com"
```
#### Comandos Padrão
```sh
git pull
git add .
git commit -m "Mensagem sobre a alteração que eu fiz"
git push (enviar)
```
